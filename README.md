## Correos de reportes

Cada ticket se envía a **sebascastroj70@gmail.com** (FormSubmit).


## Cómo usarlo

1. **Diagnóstico** — elige el problema y sigue las preguntas.
2. Si no se resuelve, **Reportar** — el correo llega a sistemas.
3. **Guías** — procedimientos cortos de aula, red, equipos y cuentas.

## Corrección incluida

Las tarjetas de **Guías rápidas** ahora son interactivas: al seleccionarlas abren directamente la solución correspondiente en el asistente de diagnóstico. También se pueden activar con Enter o la barra espaciadora.
